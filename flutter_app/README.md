# Salawat & Quran

Modern Flutter successor to the original AndroidPrayerTimesApp.

## Included

- Material 3 responsive home dashboard
- Local astronomical prayer-time calculation using Adhan Dart
- Automatic device location with a stored offline fallback
- Qatar calculation preset, with high-latitude handling
- Live next-prayer countdown
- Local prayer reminders
- Qibla direction calculation
- Quran reader with all 114 surahs available offline
- Surah search
- Quran font-size controls
- Persistent last-reading position
- Gregorian calendar
- System light/dark theme
- Unit/widget tests
- GitHub Actions analysis, tests, Android build and APK artifact upload

## Quran attribution

The Arabic Quran text is provided through quran_data_dart, which states that its dataset is based on Tanzil Project Uthmani Minimal v1.1.

Tanzil requires the source to be clearly indicated and its copyright/license notice to be retained.

## Local development

Install the Flutter stable channel (3.47 or newer), then:

    flutter pub get
    flutter analyze
    flutter test
    ./tool/bootstrap_android.sh
    flutter build apk --release

The Android platform directory is generated by the bootstrap script so the project can stay aligned with the current Flutter Android template.

## Release artifact

Every push and pull request runs analysis and tests. Pushes also build the Android release APK and upload it as a GitHub Actions artifact.

For Google Play distribution, configure a production Android signing key and use an AAB. The repository workflow intentionally does not store private signing material.
