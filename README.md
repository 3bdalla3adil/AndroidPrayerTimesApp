# AndroidPrayerTimesApp

Original Android prayer-times application.

## Flutter modernization

A new production-oriented Flutter implementation is available in the flutter_app/ directory on the flutter-quran-production branch.

It adds:

- modern Material 3 UI
- prayer times calculated locally
- location and Qibla
- offline Quran reader with all 114 surahs
- Quran search/read-position persistence
- prayer reminders
- calendars
- automated analyze/test/build CI
- APK and AAB GitHub Actions artifacts

See flutter_app/README.md for setup and Quran attribution details.
